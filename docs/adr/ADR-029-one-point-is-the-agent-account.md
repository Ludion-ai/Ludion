# ADR-029：磨く一点は「AI にアカウントを持たせる1行の体験」。Gate は名札を読む受け口。凍結の一覧を決める

日付：2026-10-03（spec v2.0 §24）

## 決定

- 磨く一点は「1行で、AI が自分の鍵と名前を持つ。MCP でも Web でも同じ名前で通じる。1行で、世界中から消せる」（spec §9）。
- Gate は、この名札を読む受け口として出す。
- ローンチの範囲は spec §9.4、完璧の基準は §9.3（ONE-1〜5、MCP-1）。
- 稼働 Gate 300 までは、spec §9.5 の一覧を凍結する。画面と宣伝からは消すが、コードは捨てずに残す。

## 理由

MCP が CIMD を既定にし、名札を読む相手が標準の側から生まれた。

## 捨てた代替案

- **v1.0 の一点「Gate の可視化（恐怖を数字に）」**（spec §0 の変更表）。Gate だけを先に広げるより、名札が初日から使える（spec §9.1）。

## 見直す条件

最初の登録者の理由が、Web 中心と分かった時。

## 出典

spec v2.0 §24（ADR-029）、§0、§9。
