# ADR-030：目的の申告（`Ludion-Purpose`：read／act と一文）を一点に組み込む。署名で覆われた時だけ本人の言葉。照合の規則は一つ

日付：2026-10-03（spec v2.0 §24）

## 決定

- 形は `Ludion-Purpose: <read|act>; note=<Display String（RFC 9651）>`。機械が使うのは一語目だけ（spec §11.7）。
- 署名で覆われている時だけ「本人の言葉」として扱う。覆われていなければ「署名なしの言い分」として表示し、照合には使わない。
- 照合の規則は一つ：`read` と言って書き込んだら「矛盾」。クローラーを名乗る相手は `read` の申告とみなす。
- `note` は Gate の外に出さず、保持は7日。機械（LLM を含む）には読ませない。
- 説明のない書き込みに `purpose_required` を返すのは、サイトが選んだ経路だけ。既定はオフ。

## 理由

検知が効かない場所でも、名乗りと矛盾は確かめられる。

## 捨てた代替案

- **申告の文を機械（LLM を含む）に読ませて判断する**。spec §26 の「越えない線」。
- **ページの中で AI に問いかける**。不変条件16。問いは HTTP の応答で出す。

## 見直す条件

主要なエージェントが、半年で一つも申告しない時。
