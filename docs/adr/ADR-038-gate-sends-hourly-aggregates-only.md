# ADR-038：Gate から外に出すのは、1時間ごとの集計だけ。来訪ごとの記録はサイトの中に7日

日付：2026-10-03（人間の決定 4）

## 決定

- Gate から外（Ludion Cloud）に出すのは、1時間ごとの集計だけにする。
  - キー：経路のテンプレート・メソッドの種類・分類・判定・運営者（diver_id か名乗りのトークン。なければ `none`）。
  - 値：件数。
- 来訪ごとの時刻・IP のハッシュ・国は出さない。
- 来訪ごとの記録は、サイトの中に7日だけ置いて消す。
- 「利用者起点の来訪か」は判定しない。区別そのものを消す。
- PRIV-4 はこの形で定義する（spec v2.0.1 §12.9、§23.4）。

## 理由

- 不変条件15「人のデータは持たない。AI の行動は、運営者単位の集計でしか外に出さない」。
- 利用者の依頼で動く AI の行動は、裏にいる人の行動でもある。どの来訪がそれに当たるかは、外からは決められない。全ての来訪を同じに扱えば、線引きを間違えようがない。
- 朝のレポートに要るのは、運営者ごと・経路ごとの件数で、来訪ごとの時刻ではない。

## 捨てた代替案

- **来訪ごとのメタデータを送り続ける**（v1 の §11.7）：不変条件15 に反する。
- **利用者起点かを判定して、そうでないものだけ来訪ごとに送る**：判定を誤れば人のデータが出る。

## 見直す条件

集計だけでは、評判イベント（spec §11.13）の証拠が足りないと分かった時。その場合も、受領証のハッシュだけを送る形にとどめる。

## 出典

spec v2.0.1 §8（不変条件15）、§10.2 の6、§12.9、§23.4（PRIV-4）。
