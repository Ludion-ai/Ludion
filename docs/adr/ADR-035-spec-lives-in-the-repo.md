# ADR-035：spec の正は、リポジトリの `docs/ludion-spec.md`

日付：2026-10-03（人間の決定 1）

## 決定

- これ以降、spec の正はリポジトリの `docs/ludion-spec.md` とする。
- 人間が承認した修正は、spec を直して版を上げる（v2.0 → v2.0.1）。
- それ以外の食い違いは、これまでどおり `docs/outbox/` に書くだけにする。Claude Code は spec を勝手に直さない。

## 理由

プロジェクトのナレッジとリポジトリに同じ文書が2つあると、どちらが新しいかで迷う。オラクルとコードと同じ場所に1つだけ置けば、差分が PR で見える。

## 捨てた代替案

- **プロジェクトのナレッジを正にする**：リポジトリの中で、オラクルとの食い違いが見えない。

## 見直す条件

なし。

## 出典

spec v2.0.1 §0、§24。docs/outbox/spec-v2-diff.md。
