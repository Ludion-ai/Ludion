# ADR-032：止めるスイッチを Ludion のサーバーに置かない。判断はサイトの設定に1行で残す。止めると優遇は対にする

日付：2026-10-03（spec v2.0 §24）

## 決定

- 止めるのはサイトだけ。Ludion は自動で蹴らず、根拠と選択肢を見せるだけ（不変条件13）。
- 判断はサイトの設定に1行で残す。範囲（全ての書き込み／この経路）と期間（24時間／7日／解除まで）を選べ、1行で戻せる。1タップにするのは後で、そのときも管理画面はサイトの中に置き、サイト自身の鍵で守る（spec §12.4）。
- 止めることと優遇することは、必ず対にする。
- 止めた記録は他のサイトに配らない。止められた相手には `Ludion-Error: blocked_by_site` と help のリンクを返す。
- 誰かを止めた経路では、名乗らない自動化にも壁を当てるよう勧める（格下げ攻撃への備え）。

## 理由

中立と、通信の可否を決める立場に立たないため。単一の障害点を作らない。

## 捨てた代替案

- **Ludion のサーバーに止めるスイッチを置く**（中央の遮断）。不変条件13、spec §26 の「越えない線」。
- **全サイトで共有するブロックリスト**。spec §9.5 で凍結、§26 で「今はやらない」。

なし。
