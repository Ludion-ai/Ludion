# ADR-028：行動の測定は「申告と行動の差」に絞る。来訪を嘘・不同意・無申告に分け、蹴るのは嘘だけ

日付：2026-10-03（spec v2.0 §24）

## 決定

- 行動の測定は、エージェントが言ったこと（申告、約束、クローラーの名乗り）と、したことの差に絞る。
- 来訪を三つに分ける。
  - **嘘**：自分の約束に反した。蹴る。
  - **不同意**：約束どおりだが、サイトの希望と合わない。入れるかはサイトが決め、Ludion は裁かない。
  - **無申告**：今は蹴らない。
- 「おかしい」は「自分の言葉に反した」場合だけにする。不審の規則は透明な三つだけで、機械学習は使わない（spec §12.5）。

## 理由

意図は測れないが、約束は測れる。

## 捨てた代替案

- **意図や悪意を推定して分類する**（機械学習のスコアなど）。spec §12.5 と §26 が「検知で大手と戦わない」としている。

## 見直す条件

申告がほとんど集まらない時。

## 出典

spec v2.0 §24（ADR-028）、§12.5、§17.5、§26。
