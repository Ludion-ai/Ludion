# ADR-031：確かめるのはタダ、保証するのは有料。一点の機能は、止めることも含めて全て無料（ADR-011 を置き換え）

日付：2026-10-03（spec v2.0 §24）

## 決定

- 一点の機能は、止めることも含めて全て無料にする：名札と鍵（`init`）、消す（`revoke`）、README のバッジ、Gate（見る・決める・止める）、朝のレポート、目的の申告、scan、ドキュメント、SDK（spec §18.1）。
- お金は、記録が貯まった後の「保証」と「名簿の商用利用」から取る（spec §18.2 のはしご）。
- ADR-011（先にサイトから回収し、エージェント側は長く無料）を置き換える。

## 理由

名乗る配管を広げる側に、課金の摩擦を置かない。値段を決める力は記録に残る。

## 捨てた代替案

- **ADR-011：先にサイトから回収する**（v1.0）。
- **「止める」機能への課金**。spec §9.5 で凍結し、§18.1 で無料とした。

## 見直す条件

段階③で、記録の買い手が0社の時。

## 出典

spec v2.0 §24（ADR-031、ADR-011）、§18。
