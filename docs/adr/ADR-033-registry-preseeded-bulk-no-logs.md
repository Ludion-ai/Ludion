# ADR-033：名簿は空から始めない（公開情報で事前登録）。大口には丸ごと配る。Card Host は記録を残さない

日付：2026-10-03（spec v2.0 §24）

## 決定

- **事前登録**：主要な AI の名札を、各社が公開している文書から先に作る。最初は10件。載せるのは運営者・用途・robots.txt への態度・出典の URL・確認した日だけで、鍵は各社が自分で公開しているものを指すだけ。「本人の確認前」と明示し、運営者は自分の名札を「引き取る」だけで管理できる（spec §14.2）。
- **丸ごと配布**：大口の検証者（CDN、認証基盤、ボット対策）には、名簿を丸ごと定期的に配る。署名と版を付け、差分で配る（spec §14.3、REG-5）。
- **Card Host**：アクセスの記録を残さない。IP・UA・時刻はどこにも書かず、障害対応に要る集計（件数と遅延）だけを持つ（spec §14.4、PRIV-5）。

## 理由

初日から検証者に価値を出す。問い合わせから行き先が漏れるのを防ぐ。

## 捨てた代替案

- **名簿を空から始め、本人の登録だけを待つ**（spec §14.2、§17.2 の1）。
- **一件ずつの問い合わせ**。問い合わせ元から AI の行き先が漏れる（spec §14.3）。

## 見直す条件

事前登録に、運営者から異議が出た時。
