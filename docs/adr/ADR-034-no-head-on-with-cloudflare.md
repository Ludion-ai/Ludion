# ADR-034：Cloudflare と正面からぶつからない。読む AI は任せ、検知が効かない場所で戦う

日付：2026-10-03（spec v2.0 §24）

## 決定

- 網の上での検知と、読む AI（クローラー）の管理は、Cloudflare・robots.txt・aipref に任せる。外では Cloudflare の名前を出して比べない。
- Ludion が戦うのは、網の位置が効かない場所：ブラウザの中の AI、MCP、記録の上に載る責任。
- Cloudflare は、名簿を受け取る相手になりうる。Gate は、顧客自身の Cloudflare Workers の上でも動く。

## 理由

網の上の検知では勝てない。網の位置が効かない場所は空いている。

## 捨てた代替案

- **検知エンジンで大手と戦う**（機械学習の分類で勝負する）。spec §26 の「戦わない場所」。

## 見直す条件

Cloudflare が、動く AI の申告と責任を始めた時。
